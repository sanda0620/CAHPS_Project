# CAHPS Project

This project analyzes CAHPS survey data using R, builds a dashboard with React/Vite, and generates reports.

## Folder Structure
- `data/`: CSV data files
- `scripts/r/`: R analysis scripts
- `images/`: Plots and figures (PNG/PDF)
- `dashboard/`: React dashboard app
- `docs/`: Documentation and outputs

## Notes
The repository README is the main project documentation. The `dashboard/README.md` file has been removed because it was the default Vite template README and is not needed for this project.
