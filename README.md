# CAHPS Project

This repository contains a CAHPS (Consumer Assessment of Healthcare Providers and Systems) analytics project that combines statistical analysis, visualization, and an interactive dashboard to explore patient experience and satisfaction data.

## 📊 Project Overview

The goal of this project is to analyze CAHPS survey data to discover insights about patient experience, relationship between listening and satisfaction, and patterns in provider performance. It includes:

- R-based analytics for data cleaning, modeling, and visualization
- A React/Vite dashboard for interactive data exploration
- Organized data files, analysis scripts, and charts for reproducibility

## 🎯 Core Objectives

- Analyze CAHPS survey response patterns
- Evaluate relationships between patient listening quality and satisfaction metrics
- Build visual summaries for correlation, distribution, and regression results
- Deliver an interactive dashboard that makes findings accessible

## 📁 Folder Structure

- `data/`: CSV data files used for analysis
- `scripts/r/`: R analysis scripts and model code
- `images/`: Generated charts and figures (PNG/PDF)
- `dashboard/`: React/Vite dashboard application
- `docs/`: Supporting documentation and project outputs

## 🧪 Analysis Components

- Data cleaning and transformation of CAHPS survey variables
- Exploratory analysis of listening scores, satisfaction, and provider ratings
- Correlation analysis across key survey metrics
- Regression modeling to identify predictors of patient satisfaction
- Visualizations of distributions, trends, and model performance
